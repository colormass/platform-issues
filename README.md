# colormass - Public Issue Tracker

Welcome to the official issue tracker for the colormass platform. While our core codebase is private, we use this repository to transparently track bugs, feature requests, and community feedback.

### How to Report a Bug or Request a Feature
1. Check the **Issues** tab above to see if your bug or request has already been reported.
2. If it is a new issue, click the green **New Issue** button.
3. Please provide as much context as possible, including the version you are using, your operating system, and the exact steps to reproduce the bug.

### ⚠️ Note on Pull Requests
Because this repository does not contain the actual source code, we cannot accept Pull Requests. Any PRs submitted here will be closed. Please submit all code suggestions or fixes via the Issues tab.
